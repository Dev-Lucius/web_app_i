# Desenvolvimento Web I

Repositório destinado ao registro de estudos, exercícios e projetos desenvolvidos na disciplina de **Desenvolvimento Web I**.

## 📚 Ementa

- Arquitetura da Web
- Noções do protocolo HTTP e funcionamento de um servidor web
- Linguagem de script para desenvolvimento web no servidor
- Dados de sessão
- Integração com SGBDs e outras fontes de dados
- Noções de Web Frameworks

## 🎯 Objetivos

- Compreender a arquitetura da Web e o funcionamento da comunicação cliente-servidor
- Entender o protocolo HTTP e o papel de servidores web
- Desenvolver aplicações web utilizando linguagem de script no lado do servidor
- Manipular dados de sessão em aplicações web
- Integrar aplicações web a bancos de dados e outras fontes de dados
- Introduzir o uso de frameworks web no desenvolvimento

## 🛠️ Tecnologias utilizadas

- Linguagem de script no servidor: [PHP / Python / Node.js / outra]
- Servidor web: [Apache / Nginx / outro]
- Banco de dados: [MySQL / PostgreSQL / SQLite / outro]
- Framework web: [Laravel / Django / Express / outro]
- Ferramentas: [Git, Composer, XAMPP, Insomnia/Postman etc.]

## 🧪 Conteúdos praticados

### 1. Arquitetura da Web
- Modelo cliente-servidor
- Páginas estáticas e dinâmicas
- Papel do navegador, servidor web e banco de dados

### 2. Protocolo HTTP
- Métodos HTTP: `GET`, `POST`, `PUT`, `DELETE`
- Códigos de status HTTP
- Cabeçalhos, corpo da requisição e da resposta
- Funcionamento básico de um servidor web

### 3. Linguagem de script no servidor
- Sintaxe básica da linguagem utilizada
- Formulários e processamento de dados
- Requisições e respostas
- Organização do código da aplicação

### 4. Dados de sessão
- Criação e gerenciamento de sessões
- Autenticação simples de usuários
- Controle de acesso e armazenamento temporário de informações

### 5. Integração com banco de dados
- Conexão com SGBD
- Operações básicas: inserção, consulta, atualização e remoção
- Uso de consultas parametrizadas
- Integração com outras fontes de dados

### 6. Web Frameworks
- Noções de MVC
- Rotas, controladores e visualizações
- Organização de projetos web com framework

## 🚀 Como executar os projetos

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/nome-do-repositorio.git
```

2. Acesse a pasta do projeto:

```bash
cd nome-do-repositorio
```

3. Configure o ambiente conforme necessário.
4. Execute o servidor local.
5. Acesse a aplicação no navegador.
